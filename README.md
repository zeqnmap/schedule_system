# EduSync

> **Единая система учебного расписания.**
> От учебного плана до PDF для учащихся и преподавателей — в одной рабочей среде.

EduSync помогает учебному заведению собирать исходные данные, создавать учебные планы, автоматически формировать расписание с учётом ограничений, контролировать часы и быстро публиковать готовые документы.

## Всё для расписания — в одном месте

| Планирование | Контроль | Выдача |
| --- | --- | --- |
| Учебные годы и семестры | Фактическая и плановая нагрузка | PDF для учащихся |
| Группы и недельная нагрузка | Ведомости занятий | PDF для преподавателей |
| Дисциплины и учебные планы | Архивирование и блокировка недель | Выгрузка часов |
| Преподаватели и кабинеты | Отмены и ручные корректировки | Рассылка PDF в Telegram |

## Что умеет EduSync

### Формировать расписание, а не просто заполнять таблицу

Встроенный алгоритм на **OR-Tools CP-SAT** строит расписание с учётом учебной нагрузки и доступных ресурсов:

- пары по два занятия, до четырёх пар за день;
- приоритет ранних уроков и плотная сетка без случайных окон;
- ограничение нагрузки для каждой группы;
- индивидуальная суббота для каждой группы;
- преподаватель, второй преподаватель и до двух кабинетов на одно занятие;
- занятость кабинетов и преподавателей;
- кураторские и информационные часы как занятые слоты;
- выходные, перерывы, отпуска преподавателей и архивные недели.

Алгоритм создаёт основу, а диспетчер может вручную корректировать, добавлять или убирать занятия. Перед сохранением система проверяет накладки.

### Держать учебный процесс под контролем

EduSync объединяет справочники и рабочие инструменты:

- **Учебные годы** — семестры, выходные и календарные ограничения;
- **Справочники** — группы, дисциплины и кабинеты;
- **Преподаватели** — карточки, нагрузка и периоды недоступности;
- **Учебные планы** — дисциплины, часы, преподаватели, кабинеты и семестры;
- **Часы** — наглядное сравнение плана с уже проведёнными занятиями;
- **Ведомость** — учёт факта проведения, отмен и восстановлений;
- **Расписание** — генерация, ручное редактирование, блокировка утверждённых недель.

### Выдавать готовое расписание без ручной пересборки

Из одного источника данных можно получить:

- расписание учащихся в PDF;
- расписание преподавателей в PDF;
- ведомости и выгрузки часов;
- рассылку готовых PDF подписчикам Telegram-бота.

Бот получает документ через защищённый внутренний API и отправляет его через очередь с ограничением скорости и повторными попытками доставки.

## Роли и порядок работы

| Роль | Возможности |
| --- | --- |
| **Владелец** | Полный доступ, включая создание, изменение и удаление аккаунтов. |
| **Администратор** | Работа с учебными данными, планами, алгоритмом, документами и расписанием. |
| **Рядовой пользователь** | Просмотр доступных данных и расписания. |

Рабочий сценарий выглядит просто:

1. Создать учебный год и семестры.
2. Заполнить группы, предметы, преподавателей и кабинеты.
3. Настроить учебные планы и недельную нагрузку групп.
4. Указать выходные, перерывы, отпуска и кураторские часы.
5. Сгенерировать расписание для открытых недель.
6. Проверить часы, при необходимости скорректировать сетку и заблокировать утверждённую неделю.
7. Скачать PDF или отправить его через Telegram-бота.

## Технологии

- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic
- **Оптимизация расписания:** Google OR-Tools CP-SAT
- **База данных:** SQLite
- **Frontend:** HTML, CSS, JavaScript
- **PDF:** ReportLab
- **Инфраструктура:** Docker Compose, Uvicorn, Nginx
- **Рассылки:** Telegram Bot API, aiogram

## Быстрый запуск

### Требования

- Docker Engine и Docker Compose;
- файл `.env` с учётными данными и секретами;
- при использовании рассылки — запущенный Telegram-бот в Docker-сети `mgkap-schedule`.

### Конфигурация

Создайте файл `.env` в корне проекта:

```env
ADMIN_LOGIN=admin
ADMIN_PASSWORD=change-this-password
SESSION_SECRET=replace-with-a-long-random-secret
BOT_SHARED_SECRET=replace-with-shared-bot-secret
BOT_BROADCAST_URL=http://mgkap_schedule_bot:8081
```

### Запуск

```bash
docker network create mgkap-schedule
docker compose up -d --build
```

После запуска приложение доступно на `http://127.0.0.1:8000`.

Для публикации на VDS/VPS используйте Nginx как обратный прокси: внешний HTTP-трафик приходит на порт `80`, а Nginx передаёт запросы приложению на `127.0.0.1:8000`.

## Для чего создан EduSync

EduSync заменяет разрозненные таблицы, ручное сопоставление ресурсов и повторную подготовку документов. Система помогает быстрее собрать расписание, сохранить контроль у диспетчера и выдать актуальную версию всем, кому она нужна.
